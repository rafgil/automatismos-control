1. ¿Qué es un Sistema de Control?

Se define como el conjunto de componentes físicos conectados entre sí para regular o dirigir su actuación por sí mismos, sin intervención externa constante.

Ejemplos cotidianos:

  • Calefacción
  • Farola automática
  • Tostadora
  • Impresora 3D

Tipos de Sistemas de Control

Bucle Abierto

La señal de salida no influye sobre la acción de control. El sistema no sabe si ha cumplido el objetivo.

Entrada → [ Controlador ] → [ Actuador ] → Salida

Bucle Cerrado

La salida se mide y se compara con la entrada para corregir errores (Realimentación).

Entrada → (Error) → [ Control ] → [ Planta ] → Salida
↑___________ [ Sensor ] ___________|

Función de Transferencia G(s)

Representa la relación entre la salida y la entrada en el dominio de Laplace.

G(s) = Y(s) / X(s)

Álgebra de bloques:

  • Serie: G = G1 · G2
  • Realimentación: G = G1 / (1 + G1·H)
