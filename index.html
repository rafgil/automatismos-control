Lazo Abierto

El sistema no mide el resultado para corregirse. Funciona por tiempo o consigna fija. No tiene realimentación.

ENTRADA → [CONTROLADOR] → [ACTUADOR] → SALIDA

Lazo Cerrado

El sistema monitoriza la salida mediante sensores y la compara con la deseada para eliminar el error.

ENTRADA → ⓧ → [CONTROL] → [PROCESO] → SALIDA
↑__________[ SENSOR ]__________|

Estructura de un Sistema

Transductores (Sensores)

Convierten magnitudes físicas (luz, calor, presión) en señales eléctricas utilizables por el controlador.

Controlador (Cerebro)

Analiza el error y decide qué acción tomar (Control P, PI, PD o PID).

Actuadores

Dispositivos que actúan sobre la planta (Motores, resistencias, electroválvulas).
