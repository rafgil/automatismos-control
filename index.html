Sistemas Automáticos de Control

Tecnología e Ingeniería II - IES Salamanca

Lazo Abierto

La señal de salida no se mide ni se realimenta para corregir la acción de control. Útil cuando la relación entrada-salida es conocida y estable.

ENTRADA → [CONTROLADOR] → [ACTUADOR] → SALIDA

Lazo Cerrado

Existe realimentación. Se mide la salida y se compara con la entrada (consigna) para minimizar el error de forma continua.

ENTRADA → ⓧ → [CONTROL] → [PROCESO] → SALIDA
↑__________[ SENSOR ]__________|

Bloques del Sistema

Sensores

Transductores como LDR, Termistores (NTC/PTC) o ultrasonidos que captan la realidad física.

Controladores

Algoritmos (PID) o circuitos que calculan la señal de mando basándose en el error detectado.

Actuadores

Motores, servomotores o relés que transforman la señal eléctrica en acción mecánica o física.
