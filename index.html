Sistemas de Control

Tecnología e Ingeniería II - IES Salamanca

Resumen del Tema 9

Un sistema de control es un conjunto de componentes físicos conectados para regular su actuación por sí mismos.

Lazo Abierto Sin realimentación. Ejemplo: Tostadora o semáforo.
Lazo Cerrado Con realimentación (sensor). Ejemplo: Aire acondicionado.

Componentes principales:

  • Transductores: Transforman magnitudes (LDR, NTC, finales de carrera).
  • Comparador: Obtiene el error (Señal de entrada - Señal realimentada).
  • Controlador: Procesa el error (P, PI, PD, PID).
  • Actuador: Ejecuta la acción (Motor, Relé).

Notas Rápidas

Error (ε):

Diferencia entre el valor deseado y el real.

PID:

P: Proporcional (Rápido)
I: Integral (Elimina error)
D: Derivativo (Suave)
